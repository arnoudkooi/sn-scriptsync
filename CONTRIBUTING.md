# Feedback and contributions

This repository is source-available for transparency and security review, but it does not accept pull requests.

Please use [GitHub Issues](https://github.com/arnoudkooi/sn-scriptsync/issues) for reproducible bugs and [GitHub Discussions](https://github.com/arnoudkooi/sn-scriptsync/discussions) for questions, ideas, and feature suggestions.

For security-sensitive reports or licensing questions, contact arnoud@snutils.com.
